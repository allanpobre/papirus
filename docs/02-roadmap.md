# Papirus — Roadmap

Ordem das áreas de foco:

1. **Escrita** — editor, margem viva, captura de fatos, perguntas de continuidade, revisão de sessão, ritmo. Ver [03-fase-1-escrita.md](03-fase-1-escrita.md).
2. **Dados** — persistência confiável, formato em arquivos legíveis, backup, base para sincronização.
3. **RPG** — painel do mestre, Codex por grupo, sessões que viram propostas de eventos.
4. **Conhecimento** — afirmações como unidade de conhecimento, segredos, revelações, simulação de leitura.
5. **Demais áreas** — Atlas, Timeline, What If, Archivist.

## Dependências entre fases

- A Fase 1 define o formato do texto (editor), que a Fase 2 precisa persistir e exportar.
- Os fatos capturados na Fase 1 já são salvos num formato compatível com as afirmações da Fase 4, para que a fase de conhecimento apenas amplie o modelo, sem migração destrutiva.
